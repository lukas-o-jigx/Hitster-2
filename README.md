# Hitster CZ

Přehrávač naslepo pro vlastní karty Hitster s českými písničkami.

- Appka: https://lukas-o-jigx.github.io/Hitster-2/
- QR kód na kartě vede na `…/Hitster-2/#042` (číslo karty). Appka pustí písničku z YouTube se skrytým videem.
- Písničky jsou v `index.html` v konstantě `CARDS` (pořadí = číslo karty).
